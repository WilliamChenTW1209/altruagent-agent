# Red Alert 1v1：策略守則

> 這份檔案每次做決定都會重新讀取，直接修改就能調整策略。
> 單位和建築名稱以 `available_production` 為準；陣營（Allies / Soviets）每場隨機。

## ⚠️ 硬性規則（程式會強制執行）

- **經濟核心完成之前（2 座礦場 + 3 台採礦車 + 戰車工廠），你的 `build` 命令會被擋掉，`train` 最多只能湊到 3 個步兵。** 不用浪費命令去試。
- 經濟核心完成後，**第一優先是戰車**，不是步兵。

## 0. 最重要的三件事

1. **快比對重要**：世界每秒跑 25 tick，不會等你。每批命令短而明確（3～8 條），不要想很久下一大批。
2. **經濟不能停**：任何時候都要有生產在進行（建築、步兵、車輛至少一條佇列在跑），錢不要堆著不花。
3. **計分規則**：時間到時比 `kills_cost - deaths_cost`，再比 `assets_value`。**不要白白送兵**；打不贏就撤回來。

## 1. 開局（自動駕駛負責，你不用下這些命令）

程式會自動：部署 MCV → 電廠 → 兵營 → 礦場 → **第二座礦場** → 戰車工廠，放好每棟完成的建築、補電廠、採礦車補到 3 台。

**你在開局要做的：**
- 兵營一好就 `train e1`，count 3，先有一點防守兵力。
- 派 1 個步兵去偵察，**其他留在家**。

## 2. 中期（2～8 分鐘）：擴張經濟 + 累積部隊

- 2 座礦場、3 台採礦車由自動駕駛負責。
- 戰車工廠完成後，持續生產主力戰車：
  - Allies：`1tnk`（輕戰車）；有 `fix`（維修廠）後換 `2tnk`。`jeep` 快但脆，只用來偵察。
  - Soviets：`3tnk`（重戰車，需要 `fix`）最強；早期用 `ftrk` 或 `apc`。
- 兵營持續補步兵（`e1`，Soviets 可以加 `e2`），步兵便宜，當肉盾和清步兵。
- 蓋 1～2 座防禦塔守家（Allies：`pbox` / `gun`；Soviets：`ftur` / `tsla`），放在通往敵方基地的方向。
- 錢多過 2000 又沒在花 → 加開一座兵營或戰車工廠。

## 2.5 兵種相剋（看 `visible_enemies` 的 type 來決定出什麼兵）

| 敵方主力 | 用這個打 | 不要用 |
|---|---|---|
| 戰車（`1tnk` `2tnk` `3tnk` `4tnk`、`apc` `ftrk` `jeep`） | **火箭兵 `e3`** + 我方戰車 | 純步兵 `e1` |
| 火箭兵 `e3`、步兵 `e1` `e2` | **步兵 `e1`**、碉堡 `pbox` / `ftur`、戰車輾過去 | 戰車單獨衝進步兵群 |
| 防禦塔（`pbox` `gun` `ftur` `tsla`） | 大量戰車一起推，或炮兵（`arty` / `v2rl`） | 少量單位零散送 |

### 戰車分級（越重越強，但越貴、越慢）

| 等級 | Allies | Soviets | 需要 | 用途 |
|---|---|---|---|---|
| 輕型 | `1tnk` 輕戰車、`jeep`（偵察） | `ftrk` 防空車、`apc` 運兵車 | 戰車工廠 | 早期過渡、騷擾、追殺採礦車 |
| 中型 | `2tnk` 中戰車 | — | 維修廠 `fix` | Allies 主力 |
| 重型 | — | `3tnk` 重戰車 | 維修廠 `fix` | Soviets 主力 |
| 超重型 | — | `4tnk` 猛獁戰車 | 維修廠 + 科技中心 | 後期壓制，很貴 |

- **維修廠（`fix`）蓋好後，立刻改出中／重型戰車，停止出 `1tnk`。** 輕戰車正面打重戰車一定輸（這場就是 1tnk 對上敵方 3tnk 被打爆）。
- 輕戰車只用在：維修廠蓋好之前的過渡期、繞後打敵方採礦車。
- 敵方出重戰車 → 我方用**中／重型戰車 + 大量火箭兵**，不要用輕戰車硬碰。
- 實際能出什麼以 `available_production` 為準。

- **部隊要混編**：大約 **戰車 60% + 火箭兵 25% + 步兵 15%**。純戰車會被火箭兵剋死（上一場就是這樣損失 $2100）。
- 經濟核心完成後，兵營持續生產 `e3`（火箭兵，每個約 300），戰車工廠持續生產戰車。
- 看到敵方大量戰車 → 提高火箭兵比例；看到敵方大量步兵 → 多出 `e1` 和戰車。
- 火箭兵很脆，跟在戰車**後面**，不要讓它們打頭陣。

## 3. 進攻時機

- **部隊價值（army_value）明顯比看到的敵軍大，才主動出擊**。第一次大進攻建議至少 6～8 台戰車 + 一批步兵。
- 用 `attack_move`（不是 `move`），整批一起走，路上遇敵會自動交戰。
- 目標優先順序：**敵方採礦車 > 礦場（proc） > 戰車工廠（weap） > 電廠（powr） > 其他**。打掉經濟和生產，對方就補不回來。
- 進攻時家裡留少量兵力 + 防禦塔。
- 戰況不利（我方單位快速減少、敵方明顯更多）→ **撤回基地附近**，在防禦塔旁邊打。

## 3.5 偷襲敵方採礦車（經濟戰）

對手會專打我們的採礦車，我們也要打他的：
- 經濟核心完成後，組一支 **3～4 台快速單位的偷襲小隊**（Allies：`1tnk` 或 `jeep`；Soviets：`ftrk` 或 `3tnk`），專打敵方採礦車（`harv`）。
- 不要走正面：先 `move` 到敵方基地**側邊或後方**的礦區附近，再 `attack` 看得到的 `harv`。
- 打掉採礦車就撤，不要戀戰，也不要去打防禦塔。
- 主力部隊同時在正面施壓，讓對方顧此失彼。
- 偷襲小隊被大軍追就撤回家，保住 `kills - losses`。

## 4. 防守

- 自動駕駛已經：每台採礦車派 2 個步兵貼身保護、每座礦場旁蓋 1 座防禦塔、固定維持 8 個步兵。**那些護衛的命令會被擋掉，不用管它們。**

- 出現 `under_attack` 事件：把附近閒置的戰鬥單位 `attack_move` 到被攻擊的位置。
- 建築血量低：`repair`。
- 採礦車被攻擊：先保護採礦車，它們是經濟命脈。
- 敵人只是幾個步兵騷擾，不要全軍回防，派小隊處理就好。

## 5. 偵察

- 開局約 1～2 分鐘時，派 1 個便宜單位（步兵或 jeep）往 `enemy_base` 走，看對手在蓋什麼。
- `visible_enemies` 裡看到大量戰車 → 多蓋防禦塔、先守再反擊。

## 6. 時間快到時（remaining_seconds < 120）

- 目前**領先**（kills_cost - deaths_cost 比較高）→ 停止進攻，把部隊拉回家保命，保住 assets_value。
- 目前**落後** → 找敵方落單的單位或採礦車打，賺 kills_cost；不要正面硬衝送兵。

## 7. 常見錯誤（避免）

- 同一個建築重複下 `build` 好幾次：佇列裡已經有了就不要再下。
- 拿 MCV、採礦車、工程師去打仗：先看 `type`，只派戰鬥單位。
- 攻擊看不到的目標：只能 `attack` 視野內（`visible_enemies`）的 id；看不到就用 `attack_move` 到座標。
- 對殘骸（`wreck: true`）下命令：殘骸沒用，忽略它。
